# Sungchul Choi (최성철)

Undergraduate student in the Division of Advanced IT, Baekseok University, Korea
(B.S. in Big Data, double major in Artificial Intelligence, expected 2027.02).

I work on context compression for small language models (about 0.6B to 4B parameters) in long multi-hop question answering.

### Research
- [HOPPER](https://github.com/sungchul02/HOPPER): training-free context compression for small language models. First author, with Prof. Jin-Keun Hong. Accepted at IJIBC (publication scheduled for December 2026).
- [HOPPER-G](https://github.com/sungchul02/HOPPER-G): follow-up to HOPPER that uses the connections between documents. In progress; details will be released with the paper.

### Research tools
- [anchor-review](https://github.com/sungchul02/anchor-review): a Claude Code skill for calibrated blind mock peer review (ACL/EMNLP/NAACL, ARR).
- [korean-writing](https://github.com/sungchul02/korean-writing): a Claude Code skill for writing and revising Korean text (papers, reports, READMEs).
